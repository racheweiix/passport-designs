# EventNook passport designs

Six digital passport designs from EventNook events, as one scrolling page: each passport floats in, opens and shows
the passport inside. Two are live passports (sample attendees); four are interactive demos with "Tap to scan".

Built from `~/reel-edits/passport-showcase/site-v2` (`node build.mjs` → `out/index.html`). Published with GitHub Pages
and shown in the EventNook NEXT app as "Booth 4 - Passport programme demo".
